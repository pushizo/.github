# Contributing · Katkı

**English** — The repositories in this organization are mirrored automatically from the Pushizo main repository on
every release, so pull requests cannot be merged here directly. Please open an issue with a clear description, a
minimal reproduction and the SDK version; we apply fixes in the main repository and they ship with the next release.
Feature ideas are welcome as issues too.

**Türkçe** — Bu organizasyondaki depolar her sürümde Pushizo ana deposundan otomatik yansıtılır; bu yüzden pull
request'ler burada doğrudan birleştirilemez. Açık bir açıklama, en küçük yeniden üretim örneği ve SDK sürümüyle issue
açın; düzeltmeyi ana depoda yapar, bir sonraki sürümle yayımlarız. Özellik önerilerini de issue olarak bekliyoruz.

Security problems: see [SECURITY.md](SECURITY.md) · Güvenlik sorunları: [SECURITY.md](SECURITY.md).
